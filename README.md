- # Game Manager v0.2.0

  一款基于 Electron 的本地游戏管理工具，专注于单机游戏（尤其是 Galgame）的便捷启动、配置与攻略管理。支持自定义启动参数、转区启动、翻译工具联动，并内置了可视化的**节点式攻略编辑器**。

  ---

  ## ✨ 功能特性

  ### 📦 游戏管理
  
  - 支持三种游戏类型：**Galgame**、**RPG**、**Unity**，卡片样式按类型区分颜色
  - 拖拽添加游戏：直接将 `.exe` 或 `.bat` 文件拖入主界面，自动填充基本信息
  - 自定义封面：点击卡片图片区域，选择图片并自动复制到应用目录
  - 一键启动游戏：
    - 可配置是否使用转区工具（Locale Emulator）
    - 支持 Galgame 自动启动翻译工具（需配置路径）
  - 游戏操作：
    - 打开游戏文件夹 / 存档文件夹
    - 编辑游戏信息
    - 删除游戏（仅从列表移除）
  
  ### 🛠️ 工具集成
  - **翻译工具**：配置翻译器路径，启动游戏前可自动或手动启动
  - **MTool 集成**：若配置了 MTool 路径，主界面将显示“启动 MTool”按钮
  - **转区工具**：配置 Locale Emulator，支持游戏以转区方式运行
  - 默认启动方式设置：可全局设置 Galgame 是否默认转区
  
  ### 📝 攻略编辑器（节点式流程图）
  - 三种节点类型：
    - **一入一出**（单输入单输出）
    - **多入一出**（多个输入合并为一个输出）
    - **一入多出**（一个输入分叉为多个输出）
  - 节点操作：
    - 拖动标题栏移动节点，连线实时更新
    - 双击节点标题或端口标签直接编辑文本
    - 点击 `+` 按钮为节点增加输入/输出端口
    - 悬停显示 `-` 按钮可删除多余端口
    - 右上角 `×` 删除节点（同时删除关联连线）
  - 连线操作：
    - 从红色输出口拖拽到青色输入口建立连接
    - 双击连线可删除
    - 连线带箭头指示方向
  - 导入/导出：
    - 导出攻略为 `.gwalk` 文件（JSON 格式）
    - 导入 `.gwalk` 或 `.json` 攻略文件
  
  ### 📦 一键打包与清理
  - **打包游戏**：将游戏文件夹、存档文件夹及关联攻略文件打包为 ZIP（带进度显示）
  - **删除源文件**：永久删除游戏文件夹及存档文件夹（不可恢复）
  
  ### 🧩 其他特性
  - 自定义无边框窗口，支持拖拽移动、最小化、最大化、关闭
  - 设置界面实时生效，工具按钮动态显示
  - 数据存储于用户目录下的 `.game-manager` 文件夹，便于备份

  ## 🖥️ 技术栈
  
  - **Electron** v28.0.0 – 跨平台桌面应用框架

  ## 🚀 安装与运行
  
  ### 环境要求
  - Node.js 16+ 及 npm
  
  ### 安装步骤
  ```bash
  # 克隆或下载项目源码
  cd GameManager
  
  # 安装依赖
  npm install
  
  # 开发模式运行（带调试工具）
  npm run dev
  
  # 打包为可执行文件（需先配置 electron-builder）
  npm run build
  ```
  
  > 若未配置打包命令，可直接通过 `npx electron .` 启动。

  ## 📖 使用指南
  
  ### 首次启动
  1. 点击左侧“设置”，配置以下路径（可选）：
     - 翻译工具（如 LunaTranslator、MisakaTranslator 的 exe）
     - MTool 启动文件（支持 `.exe` 或 `.bat`）
     - Locale Emulator 的 `LEProc.exe`
     - 选择 Galgame 默认启动方式
  2. 点击“保存设置”。
  
  ### 添加游戏
  - **手动添加**：点击主页面“+ 添加游戏”，填写信息并选择程序文件。
  - **拖拽添加**：直接将 `.exe` 或 `.bat` 文件拖入主界面的虚线区域，系统会自动填充名称和路径，仅需确认或修改后点击“添加”。
  
  ### 启动游戏
  - 点击游戏卡片上的“启动”按钮，将根据游戏类型和配置决定是否转区、是否先启动翻译工具。
  - 若配置了 MTool，可点击主界面顶部的“启动 MTool”快速打开。
  
  ### 编辑攻略
  1. 点击游戏卡片上的“攻略”按钮，打开攻略编辑器。
  2. 使用顶部工具栏添加节点。
  3. 拖动节点调整位置，双击节点标题或端口标签修改文字。
  4. 从红色输出口拖拽到青色输入口创建连线。
  5. 关闭弹窗自动保存攻略。
  6. 可通过“导出攻略”按钮保存为 `.gwalk` 文件，或通过“导入攻略”加载已有文件。
  
  ### 打包与清理
  - **打包**：点击“打包”按钮，选择保存位置，程序将打包游戏文件夹、存档文件夹（若存在且与游戏文件夹不同）以及关联的攻略文件，并显示实时进度。
  - **删源**：点击“删源”按钮，将永久删除游戏文件夹和存档文件夹（操作前需二次确认）。

  ## 💾 数据存储位置
  
  所有数据默认保存在用户目录下的 `.game-manager` 文件夹：
  
  | 文件/文件夹     | 说明                              |
  | --------------- | --------------------------------- |
  | `games.json`    | 游戏列表                          |
  | `settings.json` | 用户设置                          |
  | `guides.json`   | 所有游戏的攻略数据                |
  | `images/`       | 游戏封面图片（以 `game_id` 命名） |
  
  > 此文件夹可手动备份，迁移到新电脑时直接复制即可恢复所有数据。
  
  ---
  
  ## ⚠️ 注意事项
  
  - 删除源文件操作不可逆，请谨慎使用。
  - 打包功能会压缩整个游戏文件夹，若文件夹过大可能需要较长时间。
  - 攻略编辑器中的节点画布大小为 3000×3000 像素，超出此范围可能导致节点无法显示，建议合理布局。
  - 转区功能仅支持 Windows 系统，需提前安装 Locale Emulator。
