# Game Manager - 游戏管理软件

一个基于 Electron 的游戏管理软件，用于管理 Galgame、RPG 和 Unity 游戏。

## 功能特性

### 1. 游戏管理
- 支持三种游戏类型：Galgame、RPG、Unity
- 每个游戏显示为独立卡片，不同类型有不同颜色标识
- 点击卡片图片可更换游戏封面
- **支持拖拽 exe/bat 文件到拖放区域快速添加游戏**
- **主界面一键启动 MTool（配置后显示按钮）**

### 2. 设置界面
- **翻译工具**：配置翻译工具路径，Galgame 可选择先启动翻译工具
- **MTool 翻译**：配置 MTool 启动文件（支持 exe/bat），主界面一键启动
- **转区工具**：配置 Locale Emulator 路径
- **启动方式**：Galgame 支持转区/不转区两种启动方式

### 3. 游戏操作
- 打开游戏文件夹
- 打开存档文件夹
- 启动游戏（支持转区/不转区）
- 启动翻译工具后启动游戏
- 攻略编辑器

### 4. 攻略编辑器（节点式）
- **三种节点类型**：
  - 一入一出节点
  - 多入一出节点
  - 一入多出节点
- **节点操作**：
  - 拖动节点标题栏移动位置（实时更新连接线）
  - 点击节点标题直接编辑
  - 点击子节点标签直接编辑
  - 点击 + 按钮添加输入/输出口
  - 悬停显示 - 按钮删除输入/输出口
  - 点击节点右上角 × 删除节点
- **连接操作**：
  - 从红色输出口拖动到青色输入口创建连接
  - 双击连接线删除
  - 连接线随节点移动实时更新

## 安装和运行

### 安装依赖
```bash
npm install
```

### 开发模式运行
```bash
npm run dev
```

### 打包构建
```bash
npm run build
```

## 使用说明

### 添加游戏
1. 点击"添加游戏"按钮
2. 填写游戏名称、选择类型
3. 选择程序文件（exe 或 bat）
4. 选择存档文件夹（可选）
5. 点击"添加"

或直接将 exe/bat 文件拖拽到主界面的拖放区域。

### 配置工具
1. 点击左侧"设置"
2. 配置翻译工具、MTool、Locale Emulator 路径
3. 选择 Galgame 默认启动方式
4. 点击"保存设置"

### 编辑攻略
1. 点击游戏卡片的"攻略"按钮
2. 使用工具栏添加节点
3. 拖动节点调整位置
4. 双击标题和标签进行重命名
5. 从输出口拖动到输入口创建连接
6. 关闭弹窗自动保存

## 数据存储

游戏数据和设置存储在用户目录下的 `.game-manager` 文件夹中：
- `games.json` - 游戏列表
- `settings.json` - 设置
- `guides.json` - 攻略数据
- `images/` - 游戏封面图片

## 技术栈

- Electron 28.0.0
- Node.js
- HTML/CSS/JavaScript
- fs-extra（文件操作）

## 界面主题

白色为主色调，黑色为点缀色，简洁清晰的设计风格。

- Galgame：红色 (#ff6b6b)
- RPG：青色 (#4ecdc4)
- Unity：绿色 (#96ceb4)
